I made a Windows desktop overlay for Torn using Rainmeter. It polls the Torn API and keeps the important bits visible directly on your desktop without needing a browser tab open.

[screenshot here]

**What it does**
*   Shows energy, nerve, happy, and life bars with time-to-full
*   Tracks drug, medical, and booster cooldowns with ready state
*   Shows travel status with destination, animated progress bar, and arrival countdown (and actual location when abroad)
*   Tracks Ranked War — countdown before war, live score during (enemy in red, yours in green)
*   Shows hospital/jail status with time remaining
*   Smart drug cooldown routing — switches to Faction Armory when a war is near, otherwise goes to your inventory
*   Clickable elements — energy opens gym, nerve opens crimes, cash opens stock market, etc.
*   Includes 3 independent modules: Topbar (full-width strip), Status (compact travel/war card), and Vitals (vertical bars). Use any combination you like.
*   Built-in settings panel to easily paste your API key, toggle widgets, and adjust background transparency.

**Requirements**
*   Windows 10/11
*   Rainmeter 4.5+ (https://www.rainmeter.net/)
*   Torn API key with Basic access (https://www.torn.com/preferences.php#tab=api)

**Installing**
1. Install Rainmeter
2. Extract the `OverTorn` folder from the ZIP into your `Documents\Rainmeter\Skins\` directory.
3. Right-click the Rainmeter tray icon → Refresh All
4. Load `Settings\Settings.ini` — it will prompt you for your API key.
5. Toggle on whichever modules you want to use.
